# Clousight「云计算指北」视觉重设计规格

日期：2026-07-17  
状态：已确认

## 1. 目标

将 Clousight 浏览器扩展的 Popup、仪表盘、设置及其他全页界面统一为 CloudNorth 定义的「云计算指北」视觉语言，同时保持零后端、无账号、无遥测和本地存储的产品边界。

本次改版解决以下问题：

- Popup 当前为大面积纯黑界面，信息层级和品牌感不足。
- Popup、全页界面、扩展图标使用的品牌资产不完全一致。
- “本地模拟数据”与真实数据来源不符。
- Popup 与全页主题设置脱节。
- 厂商代码名、状态样式、版本信息和空态反馈缺少统一规则。
- 存在未使用的旧 Popup CSS 和过时 HTML 入口，形成双轨视觉实现。

## 2. 已选设计方向

采用方案 A「云计算指北原生」：

- 默认浅色，并跟随设置切换浅色或深色。
- 使用品牌蓝概览卡、浅色平面表面、细边框和紧凑状态列表。
- 视觉令牌沿用 CloudNorth 的 `primary`、`success`、`warning`、`danger` 与 `slate`。
- 通过清晰摘要与异常优先层级兼顾普通用户和运维用户。

不采用固定深色运维控制台或编辑化简报作为主界面。前者延续现有暗色问题，后者不利于快速逐家检查云服务商状态。

## 3. 品牌与视觉系统

### 3.1 品牌

- 中文环境使用“云计算指北”。
- 英文环境保留“Clousight”。
- 使用 CloudNorth 的“云 + 北向箭头”Logo 作为唯一品牌图形源。
- 同一图形覆盖 Popup、全页导航、扩展工具栏及商店图标。
- 从 SVG 源重新生成 16、32、48、128px PNG 图标，避免手工维护多套图形。

### 3.2 色彩和表面

- 品牌和主操作使用 `primary-*`。
- 正常、降级、故障、维护分别使用 `success-*`、`warning-*`、`danger-*` 和维护语义色。
- 中性色统一使用 `slate-*`。
- 常规卡片采用白色或深色表面、细边框和轻微 ring；不使用大阴影。
- 状态不能只通过颜色表达，必须同时显示文字。

### 3.3 字体、间距和交互

- 保持系统字体栈或本地字体，不在扩展 Popup 引入远程字体请求。
- 标题、正文、辅助文字建立清晰字号层级。
- 交互控件使用约 200ms 的颜色过渡，并遵守 `prefers-reduced-motion`。
- 键盘操作显示 `focus-visible` 焦点环。
- 图标按钮和主要触控控件达到约 44×44px。

## 4. 界面结构

### 4.1 Popup

Popup 采用紧凑的浅色默认布局，并支持深色主题：

1. 顶部品牌区：Logo、品牌名、产品副标题和“打开仪表盘”按钮。
2. 整体状态概览卡：展示正常厂商数、厂商总数和最重要的异常摘要。
3. 云服务商列表：使用友好名称、状态文字和紧凑徽标；异常项获得更高视觉优先级。
4. 反馈区：覆盖首次加载、刷新中、空数据和错误状态。
5. 底部信息：最后更新时间、官方状态源说明、设置入口和动态版本号。

Popup 不再展示“本地模拟数据”。推荐文案为“数据来自云厂商官方状态源”，英文提供等义翻译。

### 4.2 仪表盘

- 保留现有侧栏和路由结构。
- 统一侧栏 Logo、品牌名称、导航选中态和页面间距。
- 页面顶部展示整体健康度、异常数、维护中数量和更新时间。
- 厂商卡片突出异常服务，正常状态降低视觉噪声。
- 页面布局在窄屏下改为单列或两列，避免横向滚动。

### 4.3 设置及其他页面

- 统一卡片、表单、按钮、提示条、状态徽标和空状态。
- 语言和主题等现有功能保持不变。
- 不增加账号体系、远程 API、Supabase、服务器或遥测。
- 清理未使用的旧 Popup CSS 和过时 HTML 入口，确保只有一套样式实现。

## 5. 组件与数据边界

建议建立或统一以下可复用边界：

- `BrandLogo` / `AppBrand`：统一 Logo、品牌名和尺寸规则。
- `StatusBadge`：统一四类状态的文字、颜色和可访问语义。
- 厂商展示名称映射：从 provider registry 获取友好名称，不直接显示内部代码。
- 整体状态摘要：由现有 services 数据派生正常数、异常数和最严重状态。
- 版本显示：从 Manifest 动态读取，不在 locale 文件中硬编码版本号。

数据流保持现状：Popup 或页面通过扩展后台读取云厂商公开状态源。改版不改变状态抓取、缓存和通知架构。

## 6. 主题行为

- 初始偏好为浅色。
- 用户可选择浅色、深色或跟随系统。
- Popup 与全页界面读取同一主题设置。
- 在 Vue 挂载前尽早应用主题 class，减少浅深色闪烁。
- 浅色和深色均需满足正文和状态徽标的可读性要求。

## 7. 文案与国际化

- 所有新增或修改的用户可见文案进入 `en` 与 `zh-CN` locale。
- 中文品牌名固定为“云计算指北”，英文品牌名为“Clousight”。
- 删除所有暗示 mock、demo 或模拟数据的用户可见文案。
- 状态统一为：正常、服务降级、故障、维护中，并提供英文等义文案。
- 厂商官方名称不使用全大写内部代码作为默认展示文本。

## 8. 错误和边界状态

- 首次加载：显示轻量骨架或明确加载状态。
- 刷新中：禁用重复刷新并保留当前数据，避免列表闪空。
- 无数据：说明尚未取得状态并提供重试操作。
- 拉取失败：显示非阻断错误提示，保留最后一次成功结果。
- 部分厂商失败：正常展示其他厂商，并标记受影响厂商。
- 未知状态：采用中性样式，不错误映射为“正常”。

## 9. 验收与测试

### 9.1 功能验收

- Popup、仪表盘、设置及其他页面使用统一 Logo 和视觉令牌。
- Popup 和全页主题同步，默认浅色。
- 不再出现“本地模拟数据”或同义误导文案。
- 版本号来自 Manifest。
- 厂商显示友好名称。
- 加载、空数据、错误和部分失败状态均有明确反馈。

### 9.2 质量检查

- 更新 `en` 和 `zh-CN` 后运行 i18n 相关测试。
- 为整体状态派生、厂商名称映射和版本读取补充单元测试。
- 检查键盘导航、焦点环、44px 触控目标及浅深色对比度。
- 浏览器 action Popup 固定为 360px；HTML 壳在首屏同步声明该宽度，避免扩展 Popup 自动测量时与 `vw` 形成窄宽反馈。
- 运行 `npm run lint`、`npm run typecheck`、`npm test`。
- 运行 Chrome 与 Firefox 两套扩展构建。

## 10. 非目标

- 不改变云厂商状态抓取协议。
- 不新增后端、登录、同步服务或遥测。
- 不在本次改版中新增云厂商。
- 不引入远程字体或图标字体依赖。
- 不把 Popup 改造成完整仪表盘；复杂分析继续放在全页界面。

## 11. 异常摘要、官方链接与 Logo 修正

### 11.1 Popup 异常厂商行

- 正常厂商保持单行：厂商 Logo、友好名称、状态徽标。
- `degraded`、`outage` 或 `maintenance` 厂商行展开为两层：
  1. 第一层显示厂商 Logo、名称和状态徽标。
  2. 第二层显示该厂商最严重的活动事件标题，并提供“官方详情”外链。
- 摘要优先使用 `ServiceStatus.statusMessage`，其次为 `incident.title`，再回退 `serviceName`。
- 链接优先使用事件级 `sourceUrl`；缺失时回退 registry 的 `statusPageUrl`。
- 同一厂商存在多个异常时，仅展示严重度最高、更新时间最新的一条，避免 Popup 过长。
- 外链使用 `target="_blank"` 和 `rel="noopener noreferrer"`，不得新增 host permission。

### 11.2 厂商 Logo

- 所有已注册厂商使用本地打包的官方彩色 Logo，不在运行时请求 CDN。
- 资产路径统一为 `public/images/providers/<provider-code>.svg|png`。
- 新建共享 `ProviderLogo` 组件；资产缺失或加载失败时回退为品牌首字母，不显示破图。
- Popup 全部厂商行接入 Logo；组件可供 Providers、Dashboard 后续复用。
- Logo 仅作为辅助识别，厂商名称始终保留，不能只靠图形表达。

### 11.3 “云计算指北”官方 Logo

- 权威源为 cloudNew 的 `web/public/brand/logo.png`（蓝色三栏箭头），不得继续使用旧版“蓝云 + 绿箭头”图标。
- 将权威母版复制到 monitor 的 `public/images/logo.png`，`AppBrand` 统一引用该文件。
- 扩展图标以 cloudNew 的 `web/public/brand/icon_512.png` 为生成源，生成 16、32、48、128px PNG。
- 删除或停用旧 `public/icons/icon.svg`，避免构建时重新覆盖为旧图标。

### 11.4 验收补充

- Popup 异常行展示真实事件摘要和可点击官方链接。
- 无事件 deep link 时仍能打开对应厂商官方状态页。
- 正常厂商不显示空摘要或无意义的 “No active incidents”。
- Popup 中每家厂商均显示本地 Logo，并有首字母失败回退。
- Popup、全页导航、工具栏和通知图标均使用蓝色三栏箭头官方 Logo。
- 相关聚合、Logo 回退、链接优先级和 Popup 渲染均有自动化测试。
