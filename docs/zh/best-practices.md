# 最佳实践

云计算指北 是一款快速的本地感知工具。要充分发挥它的作用，关键在于调优规则以突出
有效信号、降低噪音，并理解它的局限。

## 降低通知噪音

默认状态——没有规则——意味着没有通知。当你确实创建规则时，请让它们尽量收紧：

- **提高最低严重级别。** 将规则的最低严重级别设为 `major` 或 `critical`，这样
  你只会在真正中断时收到提醒，而不会被轻微波动或信息性更新打扰。
- **按云厂商、区域和服务收窄范围。** 一条只匹配你实际使用的云厂商、你所在区域
  以及你依赖的服务的规则，能过滤掉与你无关的事件。
- **使用多条聚焦的规则**，而非一条大而全的规则——例如一条覆盖全部的仅
  `critical` 规则，再加一条限定在主区域的 `major` 规则。

## 只启用你使用的云厂商

关闭你不使用的云厂商意味着：

- 每个检查周期的**网络请求更少**。
- **权限更少**——实验性云厂商仅在你启用时才请求主机权限，因此保持它们关闭可将
  权限占用降到最低。

## 理解局限——这不是寻呼告警

云计算指北 **仅在浏览器运行时**进行监控。它**不能**替代服务端或值班告警
（例如 PagerDuty）。

- 将 云计算指北 用作日常可见性的**快速本地感知工具**。
- 对于**可靠的寻呼告警**，请依赖各云厂商自有的状态订阅以及你专门的值班工具。

## 自带密钥（BYOK）的 LLM

如果你启用了 AI 简报：

- 使用一个**限定用途**的 API 密钥。
- 密钥**仅存储在本地**的 `chrome.storage.local` 中，**绝不同步**。
- 它仅会被发送到你配置的端点，且仅在你点击通知上的 **AI 简报**时发送。

## 隐私

- 云计算指北 **绝不回传数据**——没有后端、账号或遥测。
- 唯一的对外请求是发往**你启用的云厂商的状态数据源**，以及（可选的）**你自己的
  LLM 端点**。
- 只启用你需要的云厂商，把网络活动降到最低。
