# 常见问题

## Clousight 需要账号或服务器吗？

不需要。Clousight 是一款**零后端**扩展。没有账号、无需登录、没有服务器、没有
遥测、也没有追踪。一切都在你的浏览器本地运行。

## 它会发起哪些网络请求？

只有两类：

1. 发往你启用的云厂商**公开状态数据源**的请求。
2. 可选地，发往**你自己的 LLM 端点**的请求——但仅当你配置了它，并且仅在你点击
   **AI 简报**时。

它绝不会把你的数据发往其他任何地方。

## 我的数据存储在哪里？

所有数据——设置、订阅规则、通知历史以及可选的 LLM 密钥——都**本地**存储在
`chrome.storage` 中。LLM 密钥存储在本地，**绝不同步**。

## 支持哪些云厂商？

**已验证并默认可用：** AWS、Azure、Google Cloud、阿里云、腾讯云。

**实验性（需手动启用）：** 华为云和火山引擎。它们尚无已验证的公开数据源。启用
其中之一会触发按需的主机权限请求，在有可用端点被贡献之前可能不显示任何数据。

## 为什么我没有收到任何通知？

Clousight 只有在**订阅规则**匹配到新事件时才通知。在**没有规则**的情况下，什么
都不会通知你——不过工具栏角标仍会反映当前问题。请在订阅页面至少创建一条规则。

另外请检查：

- 设置中已启用浏览器通知。
- 规则的最低严重级别没有设得比你期望的事件更高。
- 规则的云厂商、区域和服务关键词确实能匹配上。

## 它能通过邮件、短信或电话提醒我吗？

不能。Clousight 仅发出**浏览器通知**。它不支持邮件、短信、电话或任何服务端
告警。若需要可靠寻呼，请使用云厂商自有的订阅以及你的值班工具。

## 浏览器关闭时它还能工作吗？

不能。Clousight **仅在浏览器运行时**进行监控。浏览器关闭时它不会检查状态或通知。

## 它多久检查一次？

一个周期性的后台闹钟会重新检查状态，**默认每 5 分钟一次**。你可以在设置中修改
检查间隔，也可以选择在浏览器启动时进行检查。

## 我最多能创建多少条订阅规则？

最多 **10 条**。

## "AI 简报"是什么？

如果你在设置中配置了兼容 OpenAI 的 LLM 端点，通知页面会在每个事件上显示一个
**AI 简报**按钮，用于生成简短摘要。请求直接从扩展发往你的端点；密钥始终留在本地。

## 有团队或多用户支持吗？

没有。Clousight 是单用户且本地运行的。没有账号、没有团队功能，除浏览器自身的
设置同步外也没有任何数据同步。

## 我该如何安装它？

目前从源码安装：克隆仓库，执行 `npm install`、`npm run build:extension`，然后将
`dist/` 目录作为未打包扩展加载。参见[安装](./installation.md)页面。Chrome 应用
商店和 Edge Add-ons 的上架已在规划中，但尚未发布。

## 我如何添加云厂商或翻译？

两者都欢迎，而且相当容易。详见仓库中的 `CONTRIBUTING.md`。
