# 使用指南

Clousight 在两个地方呈现多云状态：用于快速一览的紧凑**工具栏弹窗**，以及用于
筛选、查看事件详情、通知和规则的完整**仪表盘**。本页逐一介绍这些界面。

## 工具栏弹窗

点击浏览器工具栏中的 Clousight 图标即可打开弹窗。它会显示：

- 每个已启用云厂商的**当前最严重状态**。
- 一个显示降级或中断服务数量的**角标**。
- 一个可按需重新检查状态的**刷新**按钮。
- 一个打开完整界面的**打开仪表盘**按钮。

用弹窗来快速判断"现在有没有出问题？"。

## 仪表盘

仪表盘是主视图，包含：

- **状态汇总计数**——正常、降级、中断和维护。
- **筛选器**——按云厂商、区域、类别和状态缩小范围。
- **事件表格**——每个事件一行。每行都有一个**查看详情**链接，在新标签页中
  打开该云厂商的官方状态页面。

## 云厂商页面

按云厂商展示的概览。每张云厂商卡片显示当前计数和链接：

- 指向云厂商详情页面的**内部详情**链接。
- 指向该云厂商自有状态站点的**官方状态**链接。

## 云厂商详情页面

聚焦单个云厂商的事件，并提供**区域子筛选器**，让你深入查看仅你运营的区域。

## 通知页面

Clousight 已触发通知的本地历史记录。你可以：

- **将通知标记为已读。**
- 在事件上点击 **AI 简报**（仅当在设置中配置了 LLM 时）以生成该事件的简短
  AI 摘要。

通知历史存储在你的浏览器本地。

## 订阅页面

订阅规则决定**什么会通知你**。每条规则包含：

| 字段 | 说明 |
| --- | --- |
| 名称 | 规则的标签 |
| 云厂商 | 规则适用的云厂商 |
| 区域 | 要匹配的区域 |
| 服务关键词 | 匹配提到这些服务的事件 |
| 最低严重级别 | `info`、`maintenance`、`minor`、`major` 或 `critical` |
| 浏览器通知 | 匹配时是否弹出浏览器通知 |

最多可创建 **10 条规则**。

当新获取的事件匹配某条规则时，Clousight 会弹出浏览器通知，并将其加入通知页面。

> **重要提示：** 在**没有规则**的情况下，什么都不会通知你。工具栏角标仍会反映
> 当前问题，但在你至少创建一条规则之前不会收到通知。

## 设置

配置扩展的行为：

- **语言**——9 个选项：自动、English、简体中文、繁體中文、Deutsch、
  Español、Français、日本語、한국어、Português (Brasil)。
- **检查间隔**——每隔多少分钟重新检查一次状态。
- **启动时检查**——浏览器一启动就立即重新检查。
- **已启用云厂商**——开启或关闭云厂商。
- **浏览器通知**——全局开关。
- **AI 简报（可选）**——自带兼容 OpenAI 的端点：base URL、模型和 API 密钥。
  密钥**仅存储在本地**，绝不同步。

## 后台检查的工作方式

一个周期性**闹钟**（默认每 5 分钟）会唤醒后台 service worker，它重新获取已启用
云厂商的状态、更新工具栏角标，并将任何新事件与你的订阅规则进行匹配。

Clousight **仅在浏览器运行时**进行监控。浏览器关闭时它不会检查或通知。
